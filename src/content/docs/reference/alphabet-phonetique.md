## Les six qui se trompent

| Mot | L'erreur courante | La forme exacte |
|---|---|---|
| ALFA | ALPHA, avec « ph » | **ALFA** |
| JULIETT | JULIET, avec un seul T | **JULIETT** |
| WHISKEY | WHISKY, à l'écossaise | **WHISKEY** |
| X-RAY | XRAY, sans trait d'union | **X-RAY** |
| CHARLIE | Prononcé à l'anglaise seulement | **TCHAH**-li **ou** **CHAR**-li, les deux sont admises |
| UNIFORM | Prononcé à la française | **YOU**-ni-form **ou** **OU**-ni-form |

## Épeler un indicatif

Le principe est celui du manuel : on fait correspondre à chaque lettre un mot
convenu dont la première lettre est la même.

> Le mot « MARTIN » sera épelé « MIKE, ALFA, ROMEO, TANGO, INDIA, NOVEMBER ».

Pour l'indicatif d'appel **FH 2827** du voilier de référence
([À bord](/bord/)), cela donne :

```
FOXTROT HOTEL — DEUX HUIT DEUX SEPT
```

Les chiffres se transmettent **un par un**, jamais par groupes : « deux mille
huit cent vingt-sept » n'est pas une forme radio.

:::caution[La prononciation des chiffres n'est pas dans le manuel]
Il existe une table internationale de prononciation des chiffres — NADAZERO,
UNAONE, BISSOTWO… — qui figure dans certains textes de l'UIT. **Elle ne figure
pas dans le manuel de préparation de l'ANFR**, édition de juin 2025, qui a été
relu intégralement sur ce point.

`[à vérifier ANFR]` — Ce site ne publie donc pas cette table tant que sa
présence au programme du CRR n'est pas établie. Ce qui est certain, et
suffisant : **les chiffres se transmettent un par un**.
:::

## Ce qui n'est pas interrogé

L'**annexe 5** du manuel — le lexique français-anglais tiré du *Vocabulaire
normalisé de la Navigation Maritime* de l'OMI — **ne fait l'objet d'aucune
question**. Elle est utile en mer, près des côtes étrangères ; elle ne se
bachote pas.
