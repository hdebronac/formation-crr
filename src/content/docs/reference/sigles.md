**La référence rappelle, le module explique.** Ce glossaire suit celui du
manuel de préparation de l'ANFR, complété des renvois vers les modules.

Les sigles **en gras** sont ceux que le programme du CRR utilise réellement.
Les autres sont donnés parce qu'ils figurent au glossaire du manuel et qu'on
les rencontre sur les matériels ou dans la documentation.

:::caution[RLS veut dire deux choses, et le manuel le sait]
Dans le corps du manuel, **RLS** désigne la **radiobalise de localisation des
sinistres**, l'EPIRB. Dans son propre glossaire, **RLS** est traduit par
*Return Link Systems*, la fonction d'accusé de réception apparue sur les
balises **depuis 2023**.

Les deux sens sont dans le même document. Le manuel prévient lui-même qu'il ne
faut pas les confondre — c'est un point que l'examen peut exploiter, traité en
**[M13](/modules/m13-signaux-alerte/)**.
:::

:::note[Ce qui n'est pas au programme]
Les sigles relevant du **CGO**, du **CSO/LRC**, des **ondes MF-HF** et
d'**Inmarsat** figurent ici parce qu'ils situent le CRR dans le SMDSM. Ils ne
sont **pas enseignés** par ce programme : le CRR couvre la VHF, en zone A1.
:::
